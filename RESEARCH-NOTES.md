## 05. STRATEGI IMPLEMENTASI HTML5 MURNI (PURE HTML5 STRATEGY)

1. **Kepatuhan Mutlak:**
   - 0% CSS (tidak ada tag `<style>`, tidak ada atribut `style=""`, tidak ada stylesheet eksternal).
   - 0% JavaScript (tidak ada tag `<script>`, tidak ada event handler inline).
   - 0% atribut presentasi usang (`bgcolor`, `align`, `font`, `background`, `cellpadding`, `cellspacing`, `border`).
2. **Kekuatan Informasi Semantik:**
   - Menggunakan elemen HTML5 terstruktur: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<figure>`, `<figcaption>`, `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`, `<details>`, `<summary>`, `<form>`, `<fieldset>`, `<legend>`, `<label>`, `<input>`, `<select>`, `<textarea>`, `<button>`.
   - Menghasilkan pengalaman penjelajahan multi-halaman yang kaya informasi, navigasi konsisten, dan tipografi semantik yang kuat.
